# A Little World for My Sayangkuuu 💙
```
npm install
npm run dev        # buka http://localhost:5173
npm run build      # hasil di folder dist/ → upload ke Netlify / Vercel / GitHub Pages
```
- Semua teks, tanggal, kuis, caption, timeline, surat, musik: `src/config.js`
- Foto: taruh di `public/assets/images/` (photo-04.jpg … photo-15.jpg), nama bisa diubah di config
- Musik: `public/assets/music.mp3`
